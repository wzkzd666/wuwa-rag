## 3. 测试层评审结论与本次整合（2026-10-09）

### 3.1 评审发现（改前）

- 判据层测试方向正确（离线、快、双断言 intent+chars），但 **AGENTS.md 里明说「可复用」的
  回归基线有大量未落成 pytest**：`text.py`（踩坑最密的纯函数区）与 `guard.py`（防复读闸）
  两个文件**零测试覆盖**；角色名归一五类形态、`_covers` 逐位覆盖判据同样只活在文档里。
- 「全量离线」是口头约定：违规用例只会「慢 10s」不会「红」，久了必烂。
- 测试文件清单在 AGENTS.md 中已漂移（写「四个文件」，实有 10 个）。

### 3.2 整合落地（本次改动，全部在 `tests/` 内）

| 新增/修改 | 内容 | 用例增量 |
|---|---|---|
| `test_text.py` | 图标残渣 5 正 8 负、`fix_percent_units` 六条红线（`27%5%`、`1%.20%`、术语前瞻、量纲、中文数字不补）、`[n]`/`[图谱]` 剥离与 COST `[4][3][3][1][1]`→`43311` 还原、AnswerFilter 流式（含「短答案整段重复」回归）、`lock_focus` 幂等、dedup 只丢整行相同（满级表五行同材料不误杀） | ~52 |
| `test_guard.py` | 整句重复 3 次必中 / 2 次放行、周期块循环（带 `*N` 计数后缀）从**最早**块截断、退化块后跟正常内容仍能算切点（全文扫描回归）、材料计数/技能 13 行表格/短碎句负样本不命中、流式逐 token 触发 | ~14 |
| `test_team_prune.py` | 归一链五类形态 17 例 +「绝不猜着切」红线（未知 token → None）、`normalize_team` 全角/剔格/幂等、`_covers` 逐位不摊平、**等价对互 True**（严格性归调用方）、占位串判定、镜像指纹 | ~34 |
| `test_offline_gate.py` | 守卫的守卫：非回环 connect/getaddrinfo 必须真的 RuntimeError（防 fixture 条件恒假的静默失效） | 3 |
| `conftest.py` | autouse `_block_external_network`：拦截非回环 socket/DNS；**放行回环**（Windows asyncio 的 socketpair 走 127.0.0.1 回连，全禁会让所有异步用例假失败） | — |
| `test_security_fixes.py` | 补 `_DECRYPT_ERRORS` 用例：钉住「InvalidToken 不是 ValueError 子类」这个实测推翻的想当然假设 | 1 |

**结果（实测）**：`uv run pytest` → **358 passed**（260 → 358，+98），运行 3.9s；
把 PG/Neo4j/Redis/Ollama/S3 五件套全部指向不可达端口后重跑 → **仍 358 passed / 4.6s**，
离线契约在硬闸保护下成立。`uv run ruff check tests src` 全绿。

写用例过程中一次真实抓包：`strip_icon_placeholders("凌霄：++；+++")` 的预期最初写成
`"凌霄："`，实测为 `"凌霄：；"`（句读是正文不该清）——先探测真实行为再落断言，
避免把「我以为的规则」写成测试。

## 4. 风险与遗留缺口（按优先级）

| 级别 | 发现 | 证据 | 置信 | 验证路径 |
|---|---|---|---|---|
| 中 | **eval 基线口径漂移**：README 仍写 `Avg Recall@6=0.3867`（旧口径），AGENTS.md 已是分组的 ceiling 口径（manual 1.0000 / 真缺口 4/14） | 仓库两处文本 | 高 | 重跑 `tests/eval_retrieval.py` 统一为一份基线 |
| 中 | **检索质量评测未进门禁**：eval_retrieval 依赖真实索引与 CPU reranker，只能手动跑，改 RRF/topk 无自动化回归 | 仓库脚本头注释 | 高 | 有数据的机器上加 marker 化（`-m eval`），CI 可选跑 |
| 中 | **TTS 音频 URL 跨域播放待验证**（AGENTS.md 明示）；不通则需服务端转发字节流 | 记录 | 中 | 浏览器实测一次 |
| 低 | **5 段串**（wiki 一格挤多队）不在 `_covers` 射程（只比位置数相同的串） | AGENTS.md 已知未解决 | 高 | 数据侧拆格或扩展判据，需新负样本防误杀 |
| 低 | **8G 显存双 8B 互抢**：单轮换入换出 2~3 次 × ~3s；检索静默期 ~19s 靠阶段事件缓解 | 记录（AGENTS/ARCHITECTURE） | 高 | 属部署形态约束，非代码缺陷 |
| 低 | `agent.py` 自主选工具路径保留未启用（参数名漂移历史坑） | 仓库 + 实测记录 | 高 | 接入前先解决漂移，勿动主链 |
| 低 | 限流默认进程内存计数，多实例部署需 `RATE_LIMIT_STORAGE=redis://…` | 仓库 config | 高 | 部署文档已写明 |
| 提示 | 效果数据早期：feedback 0 行、user_facts 3 条——闭环可用，但「满意度看板」尚无真实分布可评 | **实测** PG 计数 | 高 | 上线使用后回看 |

**未发现**：分层违规、循环依赖、lint 错误、离线契约破坏（本次全部实测为 0）。
